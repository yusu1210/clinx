## Unreleased

- Installed-command onboarding, command-specific help, readable default output and
  explicit `--json` for automation; bounded piped JSON inputs and actionable errors.
- Recorded Skill ownership with safe updates, recoverable removal and conflict protection.
- Bundled example copying without a checkout, installed resource discovery, and local
  CLI/Skill release bundles with checksums. No registry or release publication is implied.
- Publishable dependency locking; example copying preserves executable wrappers and
  excludes nested local state, with bounded traversal and private-file package checks.
- Multi-source coordination: task-scoped inputs, source-owned references, scoped
  navigation and a runnable cross-repository HTTP example.
- Workspace ownership guide and hands-on PRD-to-delivery tutorial with executable
  Skill/CLI steps. Source repositories need no uniform documentation scaffold.
- English and Chinese guides in `docs/en/` and `docs/zh-CN/`, with paired review
  checks; optional onboarding templates in `templates/workspace/`.
- Self-contained source/check definition snapshots and locale-independent input
  digests. Missing current inputs or retired references preserve readable history
  without supporting current acceptance.
- Source-aware observation attachments retain their origin. Explicit workspace
  aliases work for receipt paths without permitting descendant symlinks or escapes.
- Static inspection preserves valid candidates when one check directory is unusable.
  JSON parse diagnostics identify files without echoing their contents; command
  output is accumulated within independent stdout/stderr limits.
- Evaluation controls cover time precision, calendar validity, receiver semantics,
  bounded retries and uncertain outcomes. They are not agent-effectiveness results.

Receipts, checkpoints and attachments use record format 2 and evidence protocol 2;
configuration and tasks use format 1. Unsupported records require their matching
reader or newly captured evidence, not a version-field edit. This development
version is not a published release.

## 0.1.0 — 2026-09-13

Initial source release. Install from a reviewed checkout or local tarball.

- Language- and platform-neutral engineering method and portable `clinx-delivery` Skill.
- PRD/repository cold start, capability reuse, real feedback, scoped collaboration and target-specific handoff.
- Optional CLI for static inspection, non-overwriting adoption, task agreements,
  revisions, checkpoints, verification and local observation attachments.
- Explicit input bindings and strict result handling; external conditions cannot
  be approved by attaching a local pass record.
- English/Chinese documentation, runnable synthetic examples and controlled evaluation fixtures.
